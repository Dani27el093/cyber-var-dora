# Notebooks

Narrativa reproducible del proyecto. Los scripts de `scripts/` son la fuente de verdad; los notebooks sirven para explicar y visualizar.

| Notebook | Contenido |
|---|---|
| `01_eda.ipynb` | Perfil del VCDB, cobertura, sesgos y distribución de pérdidas |
| `02_severity_fit.ipynb` | Ajuste de Lognormal, Weibull, Gamma y Pareto; tests de bondad |
| `03_montecarlo_var.ipynb` | Simulación, VaR/ES, convergencia y sensibilidad |

Se crean a medida que avanzan las fases 2-4.
